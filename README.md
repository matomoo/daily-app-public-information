## ⚙️ Cara Mengaktifkan GitHub Pages (1 Menit)

Agar file-file HTML di repositori ini dapat diakses secara publik oleh Google Play Store dan pengguna:

1. Buka repositori di GitHub: [https://github.com/matomoo/daily-app-public-information](https://github.com/matomoo/daily-app-public-information)
2. Klik tab **Settings** (Pengaturan).
3. Di bilah menu sebelah kiri, klik **Pages**.
4. Pada bagian **Build and deployment > Source**, pilih:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` dan direktori `/ (root)`
5. Klik **Save**.
6. Dalam 1–2 menit, GitHub Pages Anda akan aktif di:
   `https://matomoo.github.io/daily-app-public-information/`
