Kebijakan Privasi (Privacy Policy)

Aplikasi: Daily (id.bymato.dailyapp) • Terakhir Diperbarui: 12 November 2026

1. Pendahuluan

Selamat datang di Daily, aplikasi produktivitas personal yang dikembangkan oleh ByMato ("kami"). Aplikasi ini dirancang untuk membantu Anda mengelola tugas harian (Todos), melacak kebiasaan (Habits), mencatat ide (Notes), serta membaca Mushaf Al-Qur'an 604 halaman.

Privasi Anda adalah prioritas utama kami. Dokumen ini menjelaskan jenis data yang kami kumpulkan, bagaimana data tersebut disimpan dan digunakan, serta hak Anda atas data pribadi Anda.

2. Informasi yang Kami Kumpulkan

Kami hanya mengumpulkan informasi yang sangat dibutuhkan untuk menjalankan fungsi aplikasi:

  • Informasi Akun: Alamat email dan kata sandi terenkripsi saat Anda mendaftar atau masuk ke akun Daily.
  • Data Produktivitas Pengguna: Data tugas (Todos), tanggal/jam tenggat, catatan, checklist kebiasaan (Habits), riwayat streak harian, dan label/tag catatan yang Anda masukkan ke dalam aplikasi.
  • Preferensi Pengguna: Pengaturan lokal seperti ukuran huruf, pilihan font, dan preferensi tampilan mushaf (disimpan secara lokal di perangkat Anda).

Kami tidak pernah mengumpulkan informasi lokasi presisi (GPS), kontak telepon, log SMS, atau data sensitif perangkat Anda.

3. Izin Perangkat Android (Permissions)

Aplikasi Daily meminta beberapa izin sistem Android semata-mata untuk fungsionalitas aplikasi:

  • POST_NOTIFICATIONS: Digunakan untuk menampilkan notifikasi pengingat tugas harian yang telah Anda jadwalkan.
  • SCHEDULE_EXACT_ALARM: Digunakan agar alarm pengingat tugas berbunyi secara tepat waktu pada jam yang ditentukan, meskipun perangkat dalam keadaan terkunci atau mode hemat daya (*Doze*).
  • RECEIVE_BOOT_COMPLETED: Digunakan untuk menjadwalkan ulang notifikasi pengingat Anda secara otomatis saat ponsel dinyalakan ulang (reboot).
  • INTERNET: Digunakan untuk menyinkronkan data tugas dan kebiasaan Anda secara aman ke server basis data cloud.

4. Penyimpanan dan Keamanan Data

Data akun dan catatan Anda disimpan menggunakan layanan cloud terpercaya Supabase yang berlokasi di wilayah Singapura (ap-southeast-1).

  • Enkripsi Transit: Seluruh komunikasi data antara aplikasi di ponsel Anda dan server cloud dienkripsi menggunakan protokol standar industri HTTPS / TLS 1.3.
  • Row Level Security (RLS): Akses database diproteksi ketat menggunakan aturan Row Level Security di mana data setiap pengguna hanya dapat dibaca dan dimodifikasi oleh pemilik akun yang sah.

5. Pembagian Data ke Pihak Ketiga

Kami tidak pernah menjual, menyewakan, atau memperdagangkan data pribadi Anda kepada pihak ketiga mana pun untuk tujuan periklanan atau pemasaran.

Data hanya diproses oleh penyedia infrastruktur teknis kami (Supabase) semata-mata untuk keperluan penyimpanan data dan autentikasi.

6. Hak Pengguna & Penghapusan Data

Anda memiliki kendali penuh atas data Anda:

  • Anda dapat mengedit atau menghapus tugas, catatan, dan riwayat kebiasaan kapan saja langsung dari dalam aplikasi.
  • Jika Anda ingin menghapus seluruh akun dan data Anda secara permanen dari server kami, Anda dapat menghubungi kami melalui kontak email di bawah dengan subjek "Permohonan Hapus Akun Daily". Seluruh data Anda akan dihapus dalam waktu maksimal 7 hari kerja.

7. Privasi Anak-Anak

Aplikasi Daily ditujukan untuk masyarakat umum dan produktivitas harian. Kami tidak secara sengaja mengumpulkan data pribadi dari anak-anak di bawah usia 13 tahun tanpa persetujuan orang tua.
